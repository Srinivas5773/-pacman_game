# 🟡 PAC-MAN ARCADE: CLASSIC EDITION

A clean, responsive, 60 FPS HTML5 Canvas 2D + Web Audio Synthesizer Pac-Man Arcade game featuring 4 authentic Ghost AI personalities (Blinky, Pinky, Inky, Clyde), 25 campaign mazes, and 55,000+ lines of modular datasets.

---

## 🎮 Gameplay Features
- 🟡 Smooth 60 FPS sub-pixel continuous movement with turn pre-buffering.
- 👻 4 Ghost AI Personalities (🔴 Blinky, 🌸 Pinky, 🔷 Inky, 🟠 Clyde).
- ⦿ Energizers & Frightened Ghost Hunting (200 → 400 → 800 → 1600 pts).
- 🍒 Bonus Fruit Hierarchy (Cherry, Strawberry, Peach, Apple, Melon, Galaxian, Bell, Key).
- 🔊 Pure Web Audio API Synthesizer (zero external sound dependencies).
- 📱 Touch & Mobile Swipe Controls.

---

## 🚀 How to Run
- Double-click `index.html` to play directly in your browser.
- Or start the server: `node server.js` and open `http://localhost:3000`.
